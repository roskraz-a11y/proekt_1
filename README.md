# Финансовый маршрут

Локальное приложение без зависимостей для организации небольших ежедневных шагов: задания, мотивационные баллы, кошелёк и черновики контента.

## Запуск

```bash
php -S localhost:8080
```

Откройте [http://localhost:8080](http://localhost:8080). Данные заданий и кошелька хранятся в PHP-сессии, а идеи материалов — в `localStorage` браузера. Баллы являются внутренней игровой метрикой и не представляют денежную ценность.
